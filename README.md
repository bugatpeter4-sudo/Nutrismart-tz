# 🏥 NutriSmart TZ
### Clinical Nutrition Assessment & Diet Planning System
**Morogoro Regional Referral Hospital — Pilot v2.0**

---

## 📋 Maelezo ya Mfumo

NutriSmart TZ ni mfumo wa kliniki wa lishe unaotumia AI kusaidia wataalamu wa hospitali kutoa huduma bora ya lishe. Ulioundwa mahususi kwa mazingira ya Tanzania, ukitumia vyakula vya Tanzania na guidelines za kimataifa.

---

## ✅ Vipengele Vyote

| Module | Maelezo |
|--------|---------|
| 🏠 **Dashboard** | Muhtasari wa wagonjwa wote, alerts za dharura, grafu ya wiki |
| 🩺 **Clinical Assessment** | BMI, MUAC, diagnosis kwa magonjwa 13+, Drug-Food interaction |
| 🥗 **Diet Plan (Editable)** | Mlo kamili wa kila siku, editable, printable PDF |
| 🧪 **Therapeutic Calculator** | F75, F100, RUTF, CSB+ — dozi kamili + Sound Alert |
| 🤰 **Maternal Nutrition** | Mjamzito/Kunyonyesha — parameters zote, micronutrients, complications |
| 📈 **Progress Tracker** | Trend graphs, AI analysis (Improving/Stable/Declining) |
| 📅 **Follow-up Manager** | Ratiba ya ufuatiliaji, reminders |
| 🤖 **AI Q&A** | Maswali ya lishe kwa Kiswahili — kutoka guidelines zako |
| 📚 **Guideline Library** | Weka guidelines zako mwenyewe — AI itatumia |
| 💊 **Drug-Food Checker** | Mwingiliano wa dawa na chakula (ARVs, Metformin, Warfarin, nk.) |
| 🏃 **Fitness Tracker** | BMI, BMR, TDEE, macros, workout log kwa watu wa kawaida |
| 📊 **Analytics** | Mwenendo wa malnutrition, nani wameathirika zaidi, ripoti |

## 🚀 Jinsi ya Kuendesha (GitHub + Vercel)

### Hatua 1: Pata Faili
```
Pakua faili hii (index.html) kutoka GitHub
```

### Hatua 2: Pakia GitHub
1. Nenda [github.com](https://github.com) → Sign up / Sign in
2. Bonyeza **"New Repository"**
3. Jina: `nutrismart-tz`
4. Bonyeza **"Create repository"**
5. Pakia `index.html` — bonyeza **"Add file"** → **"Upload files"**

### Hatua 3: Deploy Vercel (Bure)
1. Nenda [vercel.com](https://vercel.com) → Sign up na GitHub account
2. Bonyeza **"New Project"**
3. Chagua repository yako `nutrismart-tz`
4. Bonyeza **"Deploy"**
5. Baada ya dakika 2 — link yako: `nutrismart-tz.vercel.app` ✅

### Hatua 4: Ongeza AI ya Kweli (Hiari)
Ili AI ifanye kazi kikamilifu, unahitaji Anthropic API key:
1. Nenda [console.anthropic.com](https://console.anthropic.com)
2. Fungua akaunti na upate API key
3. Gharama: ~$5–15/mwezi kwa hospitali moja
